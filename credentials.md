# Default System Credentials & Accounts

This document contains the default user credentials generated by the application seeders (`DatabaseSeeder.php`).

## 🔑 Default User Accounts

| Role | Name | Email | Default Password | Permissions |
| :--- | :--- | :--- | :--- | :--- |
| **Super Admin** | Super Administrator | `admin@pos.com` | `Admin123!@#` | Full system access (All permissions) |
| **Cashier** | Default Cashier | `cashier@pos.com` | `Cashier123!@#` | POS access, Sales management, Customer management |

---

## 🚀 How to Seed/Reset Users

If you want to reset or populate your database with these default accounts, run:

```powershell
c:\xampp\php\php.exe artisan db:seed
```

Or run fresh migrations with seeders:

```powershell
c:\xampp\php\php.exe artisan migrate:fresh --seed
```

> [!WARNING]
> Change these default passwords immediately after installing in a production environment!
